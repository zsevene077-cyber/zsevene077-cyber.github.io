DexEval 与云端模型服务工程

参与模型评测平台及云端服务相关开发，把配置、提交、监控、结果审计和资源回收串成可跟进的实验流程。

Model Serving · Docker · Lifecycle · Python

要解决的问题

如何让一次评测的配置、执行状态、产物和资源归属对应起来？

我参与的工作

  • 参与评测工具与平台功能开发、配置核对和本地检查，结合已有工作流跟进云端执行。
  • 按部署状态、健康检查、模型身份和真实推理请求逐层检查服务。
  • 跟进运行日志和结果目录，核对 episode 覆盖、终态及归档，再处理当前实验的资源回收。

条件与范围

工程实践覆盖本地功能检查、云端作业与推理服务跟进，以及实验结果整理；不同环节按各自验证范围记录。

结果的适用范围

这里展示的是实习期间参与的工程工作与流程认识，不宣称独立负责整个评测平台，也不把本地测试通过等同于生产部署或物理机器人验收。

这项工作的启发

一个可用的评测工具，应该帮助人回答：现在运行到哪里、结果保存在哪里、还有哪些资源需要处理。
